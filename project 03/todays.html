Show & Hide

Click the button to hide and show the panel below. This pattern is used in every website — menus, dropdowns, modals, accordions.

I am the panel 👋

I can be shown and hidden by JavaScript. When I am hidden, I take up no space on the page. When shown, I slide back into view.

  • JavaScript found me with querySelector
  • It set my display to "none" to hide me
  • It set my display to "block" to show me
Second Method — Using classList

I use classList.toggle()

Instead of setting display directly, JavaScript adds and removes a CSS class called "hidden". The CSS class is what does the hiding. This is the preferred professional method.

Two methods compared

element.style.display = "none" — JavaScript writes the style directly.

element.classList.toggle("hidden") — JavaScript adds/removes a class. The CSS class .hidden { display: none } does the actual hiding. The second method keeps style in CSS where it belongs.
